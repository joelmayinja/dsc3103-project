I standardized the commodity values by stripping whitespace and converting mixed-case spellings to canonical names such as Maize and Beans so the same item is treated consistently. I treated negative prices and invalid dates as data errors and rejected those rows, while missing market values were imputed as Unknown because they are incomplete but not necessarily unusable. I distinguished an outlier from an error by looking at the price histogram and the broader distribution: values far from the main cluster were inspected, but only rows with impossible values or broken records were rejected. Leakage would include using future information, such as a market’s known seasonal pattern or row-level identifiers that encode the target behavior, before train/test splitting in a predictive task.
